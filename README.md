# Городок

Небольшая браузерная градостроительная игра, написанная на React и Vite.

## Запуск

Дважды нажмите [Запустить игру.bat](C:/Users/Матвей/Desktop/lovestory/Запустить%20игру.bat). При первом запуске зависимости установятся автоматически, затем игра откроется в браузере.

Либо выполните в терминале:

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Устройство проекта

- `src/domain` — каталог зданий и чистые правила экономики;
- `src/hooks/useTownGame.js` — состояние игры, таймеры и пользовательские действия;
- `src/services/townStorage.js` — сохранение и безопасное восстановление данных из `localStorage`;
- `src/components` — самостоятельные компоненты интерфейса;
- `src/ui/App.jsx` — композиция экрана игры.

Город сохраняется автоматически. Налог появляется у жилья и бизнеса каждые 5 секунд; смена дня и ночи проходит каждые 30 секунд и её можно переключить вручную в шапке.
